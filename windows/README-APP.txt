Local Soundboard — Windows App
==============================

1. Unzip LocalSoundboard-Windows.zip
2. Open the folder
3. Double-click "Local Soundboard.exe"
4. An app window opens (no browser needed) as Streaming PC
5. On your phone (same Wi-Fi), open the phone URL shown in the app
   → choose Soundboard
6. Optional: Add to Home Screen on phone for an app icon

Tips
----
- Closing the window hides to tray. Right-click tray icon → Quit to stop hosting.
- If phone can't connect: allow "Local Soundboard" in Windows Firewall (Private).
- Port is always 3847.
